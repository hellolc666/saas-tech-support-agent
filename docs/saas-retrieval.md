# SaaS 检索消融实验

同一份33章节语料、65条用例：53条有答案、6条无关问题、6条缺失事实问题。报告记录语料和用例 SHA-256。固定 top5；CPU 热启动单次测量，不包含 Qwen 生成延迟。

|方案|Recall@5|MRR@5|无关问题拒绝率|P95 ms|
|---|---:|---:|---:|---:|
|lexical|100.00%|97.80%|66.67%|12.61|
|dense|98.11%|93.71%|100.00%|19.83|
|hybrid|100.00%|98.74%|100.00%|28.73|
|bm25|100.00%|98.58%|100.00%|22.24|
|rrf|100.00%|98.11%|100.00%|32.06|
|rerank|100.00%|100.00%|100.00%|5496.87|

保留 Hybrid 为生产默认。RRF 未改善 MRR；CrossEncoder 将 MRR 从98.74%提高至100%，但 P95 从约29ms增加到约5497ms，因此仅保留为可复跑实验。BM25、RRF 和重排没有强行加入默认请求链。

Recall/MRR 仅针对53条有答案检索题。无关问题拒绝率仅针对6条无关问题；6条缺失事实问题不计入该指标，不能据此声称整体回答拒答准确率100%。本实验评价检索排序，不代表模型答案正确率。生产路径返回 top2；实验 top5 用于统一比较。

复跑：`uv run python scripts/evaluate_saas_ablation.py`。原始逐项结果：`data/evaluation/saas_ablation.json`。
