# 星河协作平台技术支持知识库

> 演示项目的虚构产品文档，版本 0.1。下述产品功能、限制和处理流程均为项目自定义规则，不代表真实软件服务。用于验证 RAG 检索、引用及后续工单协作。

## 产品定义与适用范围

星河协作平台是本演示项目虚构的企业项目管理软件，支持项目、成员、角色和任务管理。提供云端版和私有部署版。技术支持适用于账号登录、项目权限、部署配置、版本兼容和数据导出。本文是演示知识库，不代表系统已实现所有功能；实时运行状态、用户权限和工单结果必须通过相应工具核实。

## 问题排查前需要的信息

排查技术问题时，先确认产品版本、云端版或私有部署版、具体操作、错误码和发生时间。如果已有报错截图或请求 ID，可补充脱敏后的内容。优先根据已提供的信息查找排查步骤，只追问影响判断的缺失信息。不得索要密码、完整访问令牌、API 密钥或完整数据库连接凭据。

## 403 无权限访问项目

访问项目出现 403 或“无权限”时，先确认当前登录账号和所属企业，再请项目管理员检查账号是否加入该项目、角色是否允许当前操作。访客仅能查看，编辑操作需要编辑者或管理员权限。权限调整后退出并重新登录再试。仍然出现 403 时，记录项目标识、发生时间和请求 ID，提交技术支持；不要通过公开项目或关闭鉴权来绕过权限检查。

## 401 登录失效与令牌过期

接口返回 401 或“登录已失效”时，先重新登录；API 调用者应确认访问令牌是否过期、是否属于当前环境以及认证请求头是否正确。使用管理员提供的正式渠道更新令牌，不要把完整令牌粘贴到聊天或工单中。更新后仍出现 401 时，提供产品版本、接口路径、发生时间和脱敏后的错误信息。

## 成员角色与权限

星河协作平台的项目角色分为管理员、编辑者和访客。管理员可以管理项目成员及角色；编辑者可以创建和修改任务；访客只能查看被授权的项目内容。企业成员身份不等于自动拥有所有项目权限。需要修改角色时，应联系该项目管理员；助手不能仅根据用户描述认定权限已经生效。

## 私有部署前的准备

星河协作平台私有部署前，需要确认所用产品版本，并使用该版本随附的部署配置和依赖清单。数据库连接、应用对外地址及文件存储位置应按部署文档填写。先备份已有数据，再验证数据库连通性和服务健康状态。当前知识库未收录具体安装包、镜像地址和启动命令；遇到此类问题应说明资料不足，不能编造下载链接或执行命令。

## 服务启动失败与数据库连接

私有部署后服务启动失败，且日志出现数据库连接错误时，检查数据库服务是否运行、应用到数据库的网络是否可达、配置的主机和端口是否正确、数据库账号是否具有所需权限。提供日志时遮盖密码和连接字符串中的敏感字段。不要把删除数据库或清空数据作为常规排查方法；仍然失败时收集产品版本、启动时间和脱敏日志。

## 版本兼容与批量导出

本演示产品中，批量导出功能从星河协作平台 2.0 版本开始提供，1.0 版本不支持批量导出。2.0 的 API 客户端应配套使用 2.0 的接口文档；不能直接假设 1.0 的请求参数仍然有效。用户询问功能不可用时，应先确认产品版本与角色，再判断是否属于版本不支持或权限不足。

## 导出失败与导出数量限制

星河协作平台 2.0 单次最多导出 5000 条任务记录，超过时应按项目、日期或状态筛选后分批导出。访客无导出权限；管理员和编辑者可导出其有权访问的项目数据。数据量未超限且权限正确但仍导出失败时，应提供筛选条件、记录数量、发生时间和请求 ID。助手不得宣称已生成或下载文件，除非工具确认成功。

## 升级前检查与异常处理

星河协作平台升级前，应备份数据库和配置，阅读目标版本的变更说明，并在测试环境验证关键操作。当前知识库没有完整的升级兼容矩阵及数据库回滚步骤，不能保证任意版本可直接升级或降级。升级后发生异常时，应记录升级前后版本、影响范围和脱敏日志，交由技术支持判断恢复方案。

## 技术支持工单所需信息

文档排查无法解决问题或用户明确要求人工处理时，可以建议提交技术支持工单。建议收集问题标题、产品版本、部署方式、问题描述、复现步骤、错误码和影响范围。创建前展示拟提交内容并等待用户明确确认；只有创建工具返回成功后才能告知工单编号。此章节描述目标业务规则，不能作为工单已经创建的证据。

## 知识库未覆盖的问题

当前知识库未收录收费报价、合同条款、客户的实时系统状态和具体修复完成时间。遇到未覆盖的问题，应说明现有资料不足，并建议联系对应负责人或技术支持。不能根据其他产品的惯例编造本产品规则，也不能把检索到的相似章节作为确定结论。

## 429 请求过多与配额

接口出现 429 或 RATE_LIMIT_EXCEEDED 时，先确认请求是否超过应用在当前限流窗口的额度；降低请求频率，并在下一个限流窗口再试。若持续发生，记录应用标识、请求 ID 和发生时间交给技术支持。具体应用当前配额及某次调用结果必须在验证演示应用身份后调用业务工具查询；静态文档不能证明实时配额、限流窗口的实际结束时间或故障已恢复。

## 400 请求参数错误

接口返回 400 或 INVALID_ARGUMENT 时，检查请求体是否为合法 JSON、必填字段是否缺失、字段类型是否符合当前版本接口文档。先用脱敏后的最小请求复现，并记录接口路径、版本与请求 ID。不要把 400 当作登录过期；如果返回 401，应按登录失效章节排查。

## 404 项目或任务不存在

读取项目或任务返回 404 时，先确认资源 ID、所属企业和环境是否正确，再检查资源是否已被删除或归档。为避免暴露其他企业资源，未授权访问也可能统一显示不可用；单凭 404 不能断定资源不存在。不要向未经验证的用户披露项目名称或任务内容。

## 409 并发更新冲突

同时修改同一任务返回 409 或 VERSION_CONFLICT 时，重新读取最新任务版本，核对他人的变更，再基于新版本提交。不要自动覆盖其他成员编辑的内容。若多次冲突，提供任务 ID、发生时间和脱敏请求 ID 排查。

## 500 服务内部错误

接口返回 500 时，先保留请求 ID、发生时间、环境和复现步骤。可以在确认操作可安全重试后再次尝试；对于创建或支付类写操作，须先查询结果并使用幂等标识，避免重复写入。静态文档不能证明服务已恢复，不能承诺确切修复时间。

## 502 网关或上游服务异常

出现 502 时，检查应用网关到上游服务的连通性和上游健康状态，记录网关请求 ID 与时间。私有部署应查看反向代理和应用服务日志；云端用户可通过技术工单提供脱敏证据。不能仅凭 502 判断数据库故障。

## 503 维护或服务暂不可用

出现 503 时，按提示确认是否处于计划维护窗口，并记录发生时间和请求 ID；也可能是服务负载或依赖异常。避免高频自动重试，使用退避策略并联系技术支持核实。不能凭静态知识库宣布当前正在维护。

## API 分页与结果数量

星河协作平台演示版的任务列表接口每页最多返回 100 条。需要更多结果时，应使用响应中的下一页游标继续读取，不要把第一页当成全部数据。分页游标仅对当前查询条件有效；改变项目或筛选条件后，应重新从第一页开始。

## API 请求超时与安全重试

接口请求超时不等于写入一定失败。读操作可在合理退避后重试；创建任务等写操作要先查询结果并复用同一提交标识，避免产生重复任务。持续超时时记录接口路径、发生时间、请求 ID 和网络环境，不要把提高超时值当作唯一修复手段。

## Webhook 回调配置

演示版支持为任务变更配置 HTTPS Webhook 回调。回调地址需由项目管理员设置，并能被平台服务访问。配置后应发送测试事件核对响应；回调失败时检查地址、证书、返回状态码和网络放行规则。不要要求用户关闭 HTTPS 证书校验。

## Webhook 签名校验

收到 Webhook 时，接收方应使用配置的签名密钥验证请求签名，并检查时间戳。验证失败须拒绝处理，不应因为来源 IP 看似可信就跳过校验。签名密钥只能通过正式配置渠道更换，聊天与工单中不得提交完整密钥。

## Webhook 重试与重复事件

演示平台可能因回调超时或非成功响应而重试 Webhook，同一事件可能投递多次。接收方应按事件 ID 实现幂等处理，不能把每次投递都当成新任务。若需要查具体事件是否投递成功，应通过已授权的事件记录工具查询；当前助手没有该工具，不能声称某次回调已送达。

## CSV 任务导入失败

导入任务 CSV 失败时，核对 UTF-8 编码、列名、必填字段和日期格式，并先用少量脱敏数据复现。若部分行失败，保存失败行及错误原因后修正再导入，避免把整份文件重复导入。当前知识库没有模板下载地址，助手不能编造下载链接。

## 附件上传失败

演示版单个任务附件不能超过 20 MB；超限时应压缩或拆分文件。若文件未超限，检查上传权限、网络连接和文件格式，并记录错误码与请求 ID。当前知识库不保证所有文件格式都支持；未知格式应先核对产品版本文档。

## 搜索索引更新延迟

任务修改后搜索结果短时间未更新时，先打开任务详情核对源记录是否已保存。演示平台的搜索索引异步更新，搜索结果可能短暂落后于详情；不要重复创建任务。长时间不一致时提供任务 ID、修改时间和搜索条件，由技术支持排查索引状态。

## 企业单点登录失败

启用 SSO 的企业登录失败时，先确认企业登录入口、身份提供方配置、回调地址及用户是否被分配到该应用。若出现签名或时间相关错误，由管理员核对证书与时钟。不要建议用户关闭 SSO 或共享管理员账号；收集脱敏错误码后升级处理。

## 多因素认证与设备更换

启用多因素认证后更换设备的用户，应按企业配置的正式恢复流程处理，并完成身份核验。技术支持不能通过聊天关闭 MFA，也不得索要一次性验证码或恢复代码。管理员修改认证设置后，需提醒用户重新登录验证。

## 成员邀请与邀请失效

成员邀请链接失效时，请项目管理员确认邀请是否过期、受邀邮箱是否正确，以及用户是否已加入目标企业。应由管理员通过产品界面重新发出邀请。客服不能替用户跳过企业验证，也不能把其他企业的成员资料发给提问者。

## 项目归档与恢复

归档项目后，项目默认不再出现在活跃项目列表中，但不代表已永久删除。具有管理员权限的用户应在归档列表检查项目并按界面流程申请恢复。当前文档没有永久删除后的恢复保证；遇到删除事故应立即保留项目 ID 和时间并提交人工工单。

## 审计日志查询权限

演示版审计日志记录项目成员和角色变更等操作。只有企业管理员可以在授权范围内查看审计记录；普通成员不能仅凭项目编辑权限查询企业审计日志。客服不应在聊天中直接展示其他人的完整操作记录。

## 隐私与诊断日志脱敏

排查错误时可以收集请求 ID、状态码、产品版本、脱敏日志片段和复现步骤。提交日志前应遮盖密码、访问令牌、签名密钥、完整连接串和个人信息。当前演示验证码只用于本地合成数据；任何真实生产凭据都不应进入聊天或技术工单。
